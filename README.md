# mvclips: Stay With Me lyric-video clips (11 Nov 2026)

100 plain cuts (M001–M100) from the official lyric video v5, 1920×1080, 25 fps, H.264 High, CRF 17, AAC 256 kbit/s, 4/6/8 bars on the 131 BPM grid.

- Instagram: each file was uploaded byte-for-byte to Zernio storage (sealed uploader, `uploader` branch) and scheduled as a trial reel.
- TikTok: Buffer fetches the files from this branch through raw.githubusercontent (jsDelivr only serves files up to 20 MB).

This is an orphan branch on purpose: once every clip is posted (end of November 2026) it can be deleted without rewriting the `media` branch.
